카드 짝 맞추기 소개

뒤집힌 카드 중에서 같은 그림 두 장을 찾아요. 시작할 때 몇 초 동안 모든 카드를 보여 주니 위치를 잘 외워 두세요. 혼자 기록에 도전하거나 2명이 번갈아 대결할 수 있어요.

하는 방법

  1. 테마(동물·과일·간식·우주)와 카드 수(12~24장)를 골라요.
  2. 시작을 누르면 카드를 잠깐 보여 주고 덮어요.
  3. 두 장씩 뒤집어 같은 그림이면 짝 성공! 모두 찾으면 뒤집은 횟수와 시간이 기록돼요.

이렇게 써 보세요

  • 막히면 힌트로 1초 동안 다시 볼 수 있지만, 힌트를 쓰면 최고 기록에는 남지 않아요.
  • 2인 대결에서는 짝을 찾으면 한 번 더 뒤집을 수 있어요.

회원가입 없이 무료로 쓸 수 있고, 입력한 이름과 설정은 내 기기에만 저장돼요.
