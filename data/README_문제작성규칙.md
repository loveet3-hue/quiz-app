# 문제 데이터 작성 규칙

이 폴더의 `<퀴즈id>.js` 파일 하나가 퀴즈 하나의 문제 목록이다. `_init.js`가 먼저 로드되어 `QUESTIONS`, `FLAG(code)`, `WM(file)`를 준비한다.

## 파일 모양

```js
// 국기 보고 나라 맞히기 — 문제 100개
QUESTIONS['flags'] = [
  { image: FLAG('kr'), answer: '대한민국', alias: ['한국', '남한'] },
  { chosung: true, answer: '일석이조', text: '한 가지 일로 두 가지 이득을 봄' },
  { big: '사과', text: '영어로 쓰면?', answer: 'apple' },
  { text: '세상에서 가장 뜨거운 과일은?', answer: '천도복숭아' },
];
```

## 문제 항목 (필요한 것만)

| 항목 | 뜻 |
|---|---|
| `image` | 사진 주소. 국기는 `FLAG('국가코드 소문자 2자리')`, 위키미디어는 `WM('파일 이름.jpg')` |
| `big` | 크게 보여줄 짧은 글자 (5자 이하 권장) |
| `chosung: true` | 정답의 초성을 자동으로 만들어 크게 보여줌. 이때 정답은 한글만 |
| `text` | 문제 문장 / 설명 (한 줄, 40자 안팎) |
| `ask` | 글만 있는 문제에서 '정답은?' 대신 보여줄 질문 |
| `answer` | 정답 (화면에 보여줄 정식 표기) |
| `alias` | 같이 정답으로 인정할 다른 표기 목록 |
| `hint` | 힌트. 없으면 정답의 초성(영어면 첫 글자+글자 수)이 자동 힌트 |
| `numeric: true` | 숫자 키패드 |
| `credit` | 사진 출처 (CC BY/BY-SA 사진은 필수: `"사진: 작가 · CC BY-SA 4.0"`) |
| `by` | 명화 작가 이름 (힌트에 쓰임) |

## 채점 방식 (정답·alias 정할 때 참고)

- 띄어쓰기·문장부호·영문 대소문자는 무시하고 비교한다. (`'워싱턴 D.C.'` = `'워싱턴dc'`)
- 5글자 이상은 1글자, 12글자 이상은 2글자 오타까지 정답 처리.
- 그러니 띄어쓰기만 다른 표기는 alias에 넣을 필요 없음. 실제로 다른 이름(예: 터키/튀르키예)만 alias에.

## 품질 원칙

1. **사실이 확실한 것만.** 애매하면 빼고, 개수가 모자라면 모자란 대로 둔다.
2. 한 퀴즈 안에서 정답이 겹치지 않게.
3. 설명 문장은 직접 쓴다 (책·사이트 문장 베끼기 금지).
4. 사람 사진, 영화 포스터, 캐릭터 이미지는 쓰지 않는다 (초상권·저작권).
5. 사진은 퍼블릭 도메인·CC0, 또는 CC BY·CC BY-SA(+credit)만. GFDL·저작권 있는 사진 금지.
